Library Management System

A web-based Library Management System developed using Django and Django REST Framework.

Features

- Add books
- View books
- Edit book details
- Delete books
- Search books
- Form validation
- REST API
- SQLite database

Technologies Used

- Python
- Django
- Django REST Framework
- HTML
- CSS
- JavaScript
- SQLite
- Git & GitHub
- Postman

CRUD Operations

Operation| Method
Create| POST
Read| GET
Update| PUT / PATCH
Delete| DELETE

API

Books API:

"/api/books/"

How to Run

pip install -r requirements.txt
python manage.py migrate
python manage.py runserver

Open "http://127.0.0.1:8000/"

Project Status

CRUD operations and REST API have been implemented and tested successfully.
